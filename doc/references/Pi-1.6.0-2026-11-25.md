# Pi 1.6.0 验证（2026-11-25）

`0.2.1` 在 Pi 1.6.0 开发依赖下通过 `npm run check`，两个测试文件共 8 项通过。

从隔离的主目录和工作目录加载 `npm pack` 解包产物，以 `pi --offline --no-extensions -e <解包目录> --no-session` 启动真实终端。执行 `/dusage`，界面显示刷新与关闭提示，按 `r` 后按 `Esc` 返回；同一会话载有 `pi-dstatus`，其设置预览显示无凭据的额度状态。单独加载 `pi-dusage` 并以 `-p "/dusage"` 执行，文本报告列出四个服务各自缺少凭据。

测试使用空凭据目录，未验证真实账户的额度、限流或账单响应。
