## 不在本目录的内容

- 脱敏 fixture（`test/fixtures/xai-billing-week.json`、`test/fixtures/xai-billing-missing-fields.json`）留在 `test/`，因为测试代码按相对路径读取它们；它们是测试输入，不是文档。
- 行为断言留在 `test/`（`test/xai-usage.test.ts`、`test/dfast-adapter.test.ts`），代码即断言。
- 用户可感知的历史留在根 `CHANGELOG.md`。

## 归档约定

- 验证记录追加新文件，文件名带日期与验证对象；不覆盖旧记录。
- 已归档记录不因现行行为变化而改写，只在记录内追加「后记」注明变化。
- 本机原始现场（截图、抓包、原始日志）不入库，放仓库根 `.artifacts/`（已被 Git 忽略）。
